# Category college assets

Keep category-specific college logos, brochures and future paid-landing creative inside this directory tree.

- `logos/`: local copies of official college logos when usage/source is verified.
- `brochures/`: local copies only when redistribution/partner permission is clear.
- Current pages fall back to a text monogram when a verified local logo file is not present.
- Official brochure links in `data.php` remain source-of-truth links and should be rechecked before each admission season.

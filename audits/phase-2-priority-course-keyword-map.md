## Internal-link rules

1. Each supporting article uses one descriptive anchor to its money page.
2. Specialist course pages link upward to their broad pillar; for example, Core Java, Advanced Java, Spring and Hibernate link to Java Programming.
3. Pillar pages link downward only to relevant specialisations.
4. Never use the same title, H1 and primary keyword on more than one indexed URL.
5. Do not create a city-by-city duplicate network for the same course unless each location has a distinct, real classroom/service page.

## Required content briefing before a course page is updated

- Exact approved course name
- Primary keyword and user intent
- Verified duration, mode, prerequisite and batch availability
- Actual tools/modules
- At least two real project examples
- Approved mentor/trainer facts
- Genuine review/proof references, if any
- Related course URLs and five supporting article targets

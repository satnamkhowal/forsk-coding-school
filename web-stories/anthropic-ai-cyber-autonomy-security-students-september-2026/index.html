Lesson #1

Permissions matter more when automation gets faster

Learn least privilege, short-lived credentials and secret handling so one compromised workflow cannot reach everything.

Lesson #2

Keep enough telemetry to reconstruct actions

Audit logs and traces help defenders understand which identity acted, what changed and where an automated workflow went wrong.
04
Lesson #3

Use human approval for consequential actions

AI can suggest or prepare changes, but high-impact actions need explicit authorization boundaries and rollback plans.
05
Lesson #4

Secure coding fundamentals still matter

Patching, dependency hygiene, validation, authentication and code review become more important—not less—in AI-assisted development.
06
Lesson #5

Threat-model the agent, not just the app

Ask what tools it can call, what data it can reach, how instructions are trusted and how operators can stop it safely.

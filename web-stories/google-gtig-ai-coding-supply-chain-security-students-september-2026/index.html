Google GTIG report

AI-assisted development is part of the attack surface

Google reported real campaigns targeting developers, open-source packages, coding assistants, CI/CD and cloud credentials.
02
Lesson #1

Verify dependencies, not just suggestions

An AI-suggested package is still a third-party dependency. Check origin, maintainers, versions and project reputation before installation.
03
Lesson #2

Review workspace instructions

IDE, agent and repository configuration can influence what tools execute. Treat those files as security-relevant code.
04
Lesson #3

Protect CI/CD credentials

Use least privilege, protected environments, short-lived credentials where possible and careful review of workflow changes.
05
Lesson #4

Keep humans in high-impact decisions

AI can recommend actions. Sensitive deployments, permission changes and irreversible steps should still require explicit review.
06
Lesson #5

Confidence is not evidence

Verify code, package provenance, permissions and test results independently—even when an assistant sounds certain.
